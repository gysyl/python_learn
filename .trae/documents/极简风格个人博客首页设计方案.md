我已加载前端设计技能，将为您打造一个极简主义（Minimalist）风格的个人博客首页。

**设计理念**
我们将采用 **"Editorial Minimalist"（编辑极简主义）** 风格。
- **核心特质**：大量留白、强烈的排版对比、无装饰的线条、极致的单色或双色调。
- **视觉焦点**：内容即设计。通过字体大小、粗细和间距来构建视觉层级，而非依赖图片或颜色。
- **交互体验**：细腻的微交互（Micro-interactions），如链接的下划线动画、微妙的滚动淡入效果。

**实施计划**

1.  **项目结构初始化**
    - 在 `web/` 下创建一个新的独立目录 `blog_minimal/`，避免干扰现有 Django 项目。
    - 结构：
      ```
      web/blog_minimal/
      ├── index.html      # 语义化 HTML5 结构
      ├── style.css       # 现代 CSS (Variables, Flexbox/Grid)
      └── script.js       # 轻量级交互 (Intersection Observer)
      ```

2.  **构建 HTML 结构 (index.html)**
    - **Header**: 极简 Logo（纯文字） + 隐藏式/简约导航。
    - **Hero Section**: 大号衬线体（Serif）Slogan，配合极简的个人介绍。
    - **Article List**: 列表式布局，仅保留日期、标题和简短摘要，强调阅读节奏感。
    - **Footer**: 简单的版权信息与社交链接。

3.  **设计样式系统 (style.css)**
    - **字体**：选用 Google Fonts 组合。
      - 标题：*Playfair Display* (优雅衬线体) 或 *Cormorant Garamond*。
      - 正文：*Lato* 或 *Inter* (干净无衬线体)。
    - **配色**：
      - 背景：`#FAFAFA` (米白/纸张色) 或 `#FFFFFF`。
      - 文字：`#1A1A1A` (近黑) 和 `#666666` (深灰)。
      - 强调色：仅用于链接 hover，例如 `#D4AF37` (暗金) 或纯黑线条。
    - **排版**：使用 `clamp()` 实现流畅的响应式字体大小；严格的网格系统控制间距。

4.  **添加微交互 (script.js)**
    - 简单的滚动入场动画（元素随滚动轻微上浮并淡入）。
    - 鼠标悬停文章标题时的细微反馈。

**预期效果**
一个像高端杂志排版一样的博客首页，加载速度极快，专注于阅读体验，且在任何设备上都保持优雅。
